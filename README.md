# Simulator + NN 

A tool for simulating and training a reinforcement learning pipeline for wheeled mobile robots(tank drive). 

### Prerequisites

Matplotlib

PyTorch

Numpy

### Setup

Clone the repository:

git clone git@github.com:Aiden-Wang44/SimulaterNNV2.git

Install the project dependencies:

pip install
